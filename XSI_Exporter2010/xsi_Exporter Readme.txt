Name:		XSI Exporter 2010 v1.0
Type:		3D Studio Max 2010 Plugin
Author:		Pandemonic Studios,
		Fixed for max8 by Blake "Dummy" Robinson
Created:	15th May 2009
Tools used:	MSVC.NET
Target game:	Battlezone 2
		3D Studio MAX 2010

Description:
XSI exporter for 3D Studio MAX that allows you to export XSI 
files that are compatible with Battlezone 2. This lets you 
create new ships and units for the game. This is simply an 
updated version of the official exporter, modified to work 
on 3dsmax 2010

-----------------------------------------------------------


Installation:
Unzip xsi_Exporter.dle into your 'plugins' folder located in
your 3D Studio MAX 2010 directory. Do not use this on 
older versions of 3D Studio Max as it may not work.

-----------------------------------------------------------


Uninstallation:
If you wish to remove this plugin you can simply delete the 
following file(s):

plugins\xsi_Exporter.dle

-----------------------------------------------------------


Distribution:

These files may only be redistributed if this readme is included.
