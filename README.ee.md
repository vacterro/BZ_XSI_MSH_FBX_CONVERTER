# bzconv — Battlezone XSI/MSH konverter

Windows C++20 konverter Battlezone 2 XSI ja DOCB MSH mudelitele. GLB, glTF ja
OBJ eksport töötab otse; FBX eksport kasutab paigaldatud Blender 4.x/5.x ja
kaasasolevat Blenderi silda.

Portatiivne versioon: `release/README.txt`. Käsurea abi: `bzconv --help`.

Praegune versioon: **v0.0.1**

Kontrolli staatused on eristatud: `FILE_WRITTEN`, `STRUCTURALLY_VALID`,
`GEOMETRY_VERIFIED`, `FULL_SCENE_VERIFIED`, `PARTIAL_LOSS`.
